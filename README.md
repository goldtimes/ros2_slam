# 定位建图算法
重构的一版本定位建图算法，目前支持lidar/imu/encoder/gnss等传感器，未来会支持相机传感器.
该算法的核心是ieskf算法，为什么采用ieskf算法，因为目前对它的理论和代码编写比较熟悉。基于优化的方式代码会比较困难
# 目标
这是一个紧耦合的框架，初步目标是实现多传感器的定位建图，后续需要对系统稳定性的完善，比如某个传感器断连后，我们依然可以稳定的工作。
如果无法工作，识别定位丢失后，通过鲁棒的定位方法进行定位恢复。
需要支持动态地图的更新，比如车辆行驶过程中，会有新的环境出现，需要动态的更新地图，也就是life long的slam.
